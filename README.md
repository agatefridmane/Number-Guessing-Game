I built a desktop number-guessing game using Java Swing. The game randomly picks a number from 1 to 10. The player types a guess and clicks OK. If the guess is wrong, the game tells the player whether the secret number is higher or lower. It also shows an error for invalid input. Clicking New Game clears the input, resets the attempt counter, and picks a new number. This project gave me practice building a graphical interface, handling button clicks, validating input, and tracking the game’s state. One detail in the current code: The interface promises three attempts, but after two wrong guesses it displays “You lose!” on the next numeric submission without checking whether that guess is correct.
